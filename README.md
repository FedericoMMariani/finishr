# Finishr

Campionato a punti delle gare di paese, anche non competitive.

- `index.html`, `app.js`, `manifest.json`, `logo.svg`, icone: l'app (pubblicata con GitHub Pages)
- `config.js`: qui vanno l'indirizzo e la chiave pubblica del progetto Supabase
- `supabase.sql`: crea tabelle, regole di sicurezza e funzioni (da incollare una volta nel SQL Editor di Supabase). Include già le classifiche ufficiali.
- `logo-stampa/`: i file del logo per magliette e stampa, con colori e caratteri in `LEGGIMI.txt`. Non vanno caricati su GitHub.

La guida passo passo è nel documento «Guida alla pubblicazione».
